MChan

MChan is a pseudonymous community platform for Malaysian university students, with boards, threads, replies, moderation, and supporting operational systems.

Status: Active development / public beta.

Technologies:

  • Rust
  • Tokio
  • Axum
  • Askama
  • SQLx
  • SQLite
  • Docker
  • Cloudflare
  • GitHub Actions

Motivation: MChan is designed around lightweight, fast, server-rendered pages and stronger moderation than traditional anonymous imageboards.
