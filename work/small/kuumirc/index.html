KuumIRC

KuumIRC is an opinionated IRC client for UM that runs in the browser as a small web app. I built it in September 2026. It connects over a WebSocket and uses IRCv3 chat history, so a session and its history persist instead of disappearing when the tab closes.

On top of plain IRC it adds registration, image and video attachments with upload progress, drawings made with tldraw and posted into chat, channel moderation slash commands, and tab controls for hiding channels. A small command-line script lets a bot or agent account join a channel with a normal login.

The server side is a separate repository: an Ergo IRC server behind a soju bouncer, a sign-up service, and nginx, all run with Docker Compose. Uploaded media goes through the same mchan-image processor that MChan uses.
