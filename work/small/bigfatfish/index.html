BigFatFish

BigFatFish is an animated character that follows the mouse pointer on Android 16 and reacts to mouse buttons. I built it in September 2026. It needs no root: it uses an Android accessibility service plus a small helper started over ADB.

It only observes mouse input. It does not read screen content or keyboard input, and it does not change clicks. You can adjust motion, size, idle behavior, and opacity, and import your own PNG artwork pack. The default character artwork is by xian_kuang.

Source: KuuminKochi/BigFatFish (Apache 2.0 for the code; the artwork belongs to its creator).
