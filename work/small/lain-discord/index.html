Lain-Discord

Lain-Discord is realmxrza's desktop pet of Lain Iwakura, which runs as a Vencord plugin for Discord or as a script on a website. It is not my project; I contributed to it in July and August 2026.

My main contribution was a refactor that split rendering from the pet logic, so the pet code only handles movement and interactions. It also added parabolic and sinusoidal movement and fixed the bugs that existed at the time. It was merged upstream in August 2026.

Source: realmxrza/Lain-Discord.
